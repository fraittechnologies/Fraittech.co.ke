## 🎯 How It Works

### Contact Form:
```
Fill form → Click "Send Message"
         → Button shows "⟳ Sending..."
         → No page reload
         → 1-2 seconds wait
         → Green "Success!" appears
         → Form clears
         → Message auto-hides after 5 seconds
         → Email confirmed in inbox
```

### Quotation Form:
```
Fill form → Click "Submit Quotation Request"
        → Button shows "⟳ Submitting..."
        → Modal stays open
        → No page reload
        → 1-2 seconds wait
        → Green "Success!" appears
        → Modal closes after 3 seconds
        → Back on quotation page
        → Email confirmed in inbox
```
